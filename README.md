# Arduino Uno I/O Shield

An Arduino Uno shield I designed in KiCad, had fabricated, and soldered by hand. It adds a
10-bit R-2R ladder DAC (10 kΩ / 20 kΩ, on D0–D9) buffered by an MCP6002 op-amp, 3.5 mm
audio in and out jacks, two pots, two buttons, and headers for an MPU6050 IMU and an
SSD1306 OLED.

Write-up: https://nruth633.github.io/projects/io-shield.html

The KiCad project is in `UNO_shield_1/` (open `ShieldV1.kicad_pro` in KiCad 9 or newer),
along with the gerbers and BOM.
